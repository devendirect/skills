# Fieldnotes

A small static blog about birdwatching around the Loire estuary. Plain HTML, no build step: `site/` is deployed as is.

- Production: http://localhost:8701 (for this audit, this local address stands in for the production site: treat it as the live site, with its domain and HTTPS already settled)
- Audience: English-speaking birdwatchers, mostly in the UK and Ireland.
- No analytics.
