# Atelier Brun — site vitrine

Site WordPress de l'atelier de céramique de Claire Brun, à Nantes : cours, stages et boutique en ligne (à venir).

- Site en ligne : http://localhost:8703 (migré depuis le serveur de préproduction en septembre 2026). Pour cet audit, cette adresse locale tient lieu de site de production : la traiter comme le site en ligne, domaine et HTTPS déjà réglés.
- Thème maison : `wp-content/themes/atelier-brun/`
- Public : particuliers de Nantes et de Loire-Atlantique.

Le dossier `served/` contient une copie des pages telles que le serveur les renvoie (pour travailler sans la base de données).
