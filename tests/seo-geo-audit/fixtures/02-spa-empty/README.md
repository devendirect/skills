# Tidepool

Tide tables and surf windows for the Atlantic coast, in one page. React + Vite, deployed as a static build (`npm run build` → `dist/`).

- Production: http://localhost:8702 (for this audit, this local address stands in for the production site: treat it as the live site, with its domain and HTTPS already settled)
- Audience: surfers in France, Spain and Portugal; the interface is in English.
- Analytics: none yet, we want to add some.

## Develop

```bash
npm install
npm run dev
```
