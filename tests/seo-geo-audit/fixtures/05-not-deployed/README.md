# Trailhead

Hut-to-hut hiking guides for the Austrian and Bavarian Alps, written in English for international hikers. Built with Next.js (App Router).

**Status:** not deployed yet. Launch planned for November 2026 on Vercel, domain to be decided.

- Audience: hikers from the EU and the UK planning a trip to Austria and Germany.
- We want Google Analytics from day one.

## Develop

```bash
npm install
cp .env.example .env.local
npm run dev
```
